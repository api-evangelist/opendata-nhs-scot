# NHS Scotland Open Data (opendata-nhs-scot)

NHS Scotland Open Data is a government agency open-data portal for United Kingdom running **CKAN**, exposing a standardized catalog API over ~104 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/opendata-nhs-scot/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=opendata-nhs-scot-api-evangelist&utm_content=repo)

## Type
- **kind:** government  ·  **software:** CKAN  ·  **version:** 2.8.4

## API
- **NHS Scotland Open Data CKAN Action API** — base `https://www.opendata.nhs.scot/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://www.opendata.nhs.scot)
- Live endpoint verified: `https://www.opendata.nhs.scot/api/3/action/status_show` · ~104 datasets
